# 智行校园实施记录

用户批准：完整前端，三餐、六类记录、演示账号、真实校园地图；手表留待未来。

技术：React + TypeScript + Vite + React Router + CSS Modules。现有目录没有 Git 仓库，新前端独立放在 frontend，不移动原 Python 文件。

决策：地图地点由高德校园范围检索解析坐标，不复制旧项目坐标。未配置 Key 时诚实呈现配置/失败状态，不生成虚构地图。地图安全码通过开发服务器代理提供；生产部署需同等代理。

决策：演示会话存 sessionStorage；个人资料与业务记录按稳定用户 ID 分区保存。密码仅在表单内存中存在。

实施顺序：领域测试 → 数据层 → 账号与布局 → 页面/地图 → 联动 → 验证与说明。
