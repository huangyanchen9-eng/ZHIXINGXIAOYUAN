# 智行校园 · 前端与真实账号接入

手机优先的校园生活应用，适配大连海事大学凌水校园范围。保留原 Python 项目，新界面独立运行。

当前主题为“海大青春蓝”：海洋蓝主色 `#1473C9`，浅天蓝与白色背景。公共颜色变量集中在 `src/global.css` 的 `--campus-*` 中，插画、图表和地图路线颜色同步更新。

## 启动

需要 Node.js 24。先按项目根目录 README 启动后端，再在 `frontend` 文件夹中打开终端：

```powershell
npm install
npm run dev
```

浏览器打开终端显示的地址，默认是 http://localhost:5173 。使用“林同学”或“陈同学”按钮直接进入，无需密码。填写注册表单将创建真实账号，数据保存到本机后端数据库。

```powershell
npm test             # 领域逻辑与地图适配测试
npm run build        # TypeScript 检查和生产打包
npm run test:e2e     # 浏览器验收（自动启动隔离后端及前端，需要 Google Chrome）
```

浏览器验收会写入隔离的临时浏览器上下文，不访问个人 Chrome 资料。测试使用独立数据库和5174/8001端口，不影响日常账号。截图存于 `screenshots/`，失败轨迹存于 `test-results/`。

## 真实地图配置

1. 在高德开放平台准备 **Web 端（JS API）** 类型的 Key 和配套安全密钥，确保启用所需地点查询、步行与骑行能力。
2. 复制 `.env.example` 为 `.env.local`，在本机填写：

```dotenv
VITE_AMAP_KEY=你的网页地图Key
AMAP_SECURITY_CODE=配套安全密钥
```

3. 重启 `npm run dev`。按账号平台要求配置允许使用的本地域名。
4. 打开“出行”，搜索具体校园建筑，选择结果后规划路线。结果不唯一时人工确认地点；多任务规划使用精确地点名称。

Key 是网页客户端标识。安全密钥不带 `VITE_` 前缀，由 Vite 本地开发服务器的 `/_AMapService` 代理添加；不会写进浏览器构建产物。`.env.local` 已忽略，不应提交。

正式部署 `dist` 时必须额外配置等效服务端代理和 SPA history fallback。`vite preview` 仅预览静态资源，不提供这个地图安全代理。当前没有部署线上站点。

地图底图、地点与道路均来自高德在线服务；地点搜索限定大连，并在大学中心附近检索，不复用旧 demo 的样例坐标。需要使用者核对建筑入口与校园实际通行情况。未配置、鉴权失败、无结果或不可达时显示真实错误，不伪造道路。定位仅在主动点击后请求。跑步沿步行路线，以 7 分钟/km 估算。

## 账号与存储说明

- 注册、登录和改密已接入真实后端，学号唯一，保留前导零；未认证学校学籍。
- 密码以 scrypt 加盐派生值保存，不写入浏览器存储或日志。会话使用 HttpOnly Cookie。
- 真实账号首次进入为空白记录；全部记录、计划、偏好、积分和对话历史均保存到 SQLite。
- 演示按钮仍使用独立浏览器数据，不自动迁入真实账号。
- 多页同时修改会提示版本冲突，请刷新后重试；保存失败不退回本地假装成功。
- 导出 CSV/JSON 包含当前个人数据，不包含密码。尚不支持导入备份。
- 服务启动、接口、数据库备份和部署限制见 [后端说明](../backend/README.md)。

## 功能覆盖

| 模块       | 实现与界限                                                                       |
| ---------- | -------------------------------------------------------------------------------- |
| 今日       | 分时段建议、今日课程/待办/三餐时间线、明日课程、快捷入口                         |
| 统一记录   | 三餐、睡眠、运动、心情、课程、待办；新增、编辑、删除和账号保存                   |
| 课表       | 周视图、教学周过滤、课程冲突校验、手动编辑、课程到导航、应用内提醒               |
| OCR        | 内置示例演示识别→校对→保存；个人 PNG/JPG 仅预览及手动录入，不声称识别成功        |
| 校园导航   | 真实高德底图与 POI、步行/骑行、跑步估算、主动定位、行程保存；需要本地 Key        |
| 多任务规划 | 任务增删改排序、停留时间、起点、逐段真实路线、跨日保存；DQN 优化单独标记固定演示 |
| 三餐饮食   | 早午晚推荐、预算/口味/忌口/用餐时长筛选、健康优先排序、对比、用餐计划和实际记录  |
| 饮食分析   | 只统计“已吃”，未知营养不按零计算；示例营养与手动数据分源标记                     |
| 健康       | 日期范围、睡眠/运动/饮食/心情统计、图表与建议、LSTM 固定预测演示                 |
| 历史       | 分类/日期/关键词筛选、详情编辑删除、分类图与出行统计、CSV 下载                   |
| AI 伴航    | 持久化会话、预设场景、课程/饮食/情绪/行程回复、业务页面跳转；未调用模型            |
| 五育成长   | 原创微课、预置测验、判分和解析、重复提交不重复计分、雷达图与时间线               |
| 设置       | 资料、密码演示、偏好与权重、模型参数保存、导出、备份、当前用户数据清空与示例恢复 |

示例餐食不是食堂实时菜单；忌口筛选只依据示例食材，不保证实际供应。三餐计划不计入摄入，只有记录已吃才更新营养汇总。成长和健康演示不构成学校评价或医学结论。低碳估算沿用原项目演示系数 0.2485 kg/km，并在页面说明口径。

手表/手环不在本轮范围：无设备连接、电量、心率或通信日志的模拟页面。后续可以从后端接入设备数据。

## 比赛演示建议（约 5 分钟）

1. 登录页直接进入林同学，说明账号与数据的演示范围。
2. 首页“记录”增加待办或课程，查看时间线联动。
3. 三餐切换早午晚，设置预算与忌口，选择方案加入计划；打开营养与记录，说明未吃不计摄入，再标记已吃。
4. 配置地图后，从课程进入校园导航，搜索并选择真实地点；查看路线，保存到今日安排。或进入多任务行程逐段安排。
5. 记录跨午夜睡眠、运动与心情，在健康/历史中查看统计。下载历史 CSV。
6. 完成绿色校园微课和测验，查看积分与雷达图；重做证明不重复计分。
7. 使用 AI 伴航的三餐或路线示例，点击回复中的业务入口。
8. 切换陈同学，验证两位用户的记录互不混用。最后返回设置下载 JSON 备份。

## 后端交接

`src/services.ts` 提供账号与业务数据的异步适配接口；`src/types.ts` 定义共享类型；`src/domain.ts` 是纯计算与校验；`src/mapService.ts` 适配地图服务；`src/store.tsx` 管理用户会话与数据。

后端阶段替换服务适配层，实现学号唯一性、密码哈希、服务端会话、按会话校验数据归属、数据库持久化与跨设备同步。再接 OCR、真实 AI、DQN 与 LSTM。浏览器不得接收服务端模型/OCR 密钥。当前不改动旧 Python 代码或数据库。
