**完整云端部署：** [GitHub + 托管服务操作说明](DEPLOY.md)。仓库上传和网站上线是两个步骤；部署入口不会自动开通或购买云服务。

本轮已接入真实账号和全部业务数据保存。原 Python 项目保留；AI、OCR、DQN/LSTM 和手表接入未在本轮启用。

## 本地启动

需要 Node.js 24。第一次使用分别在 `backend` 和 `frontend` 运行 `npm install`。当前电脑依赖已安装。

打开两个终端：

```powershell
cd backend
npm run dev
```

```powershell
cd frontend
npm run dev
```

访问 <http://127.0.0.1:5173>。注册自己的学号账号，或使用下方的独立演示体验。关闭终端会停止服务，重新启动后账号与数据仍保留。

## 演示顺序

1. 注册账号（学号、密码、姓名、入学年份、专业、性别）。真实账号初始没有示例记录。
2. 首页“记录”添加课程、三餐、睡眠、运动、心情和待办。
3. 三餐页加入计划，再用“记录已吃”录入摄入；课表和今日安排同步更新。
4. 出行页查询真实高德路线、保存行程；地图需要网络和本机配置。
5. 伴学测验更新成就，AI 示例对话可保存历史；这些功能不代表已接入模型服务。
6. 刷新、退出后重新登录，确认资料与记录恢复；在“我的”修改资料或密码。
7. 设置中下载 CSV 或 JSON 个人数据备份。

详细说明：[后端、接口与备份](backend/README.md) · [前端与地图配置](frontend/README.md)。

界面沿用海大青春蓝，兼容手机与电脑。当前为本机运行，未发布云端、未认证学籍。
